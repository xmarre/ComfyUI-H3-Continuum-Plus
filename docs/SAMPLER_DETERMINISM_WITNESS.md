# H3 sampler-input identity witness

Repeated runs with the same displayed seed can differ if the sampler's effective
seed, initial noise, encoded reference latents, Qwen conditioning tensor, model
state, or kernel execution differs. The existing physical prompt SHA is a hash
of the prompt/presentation **contract**, not the numerical conditioning tensors.

For one diagnostic queue, set the process environment variable
`H3C_DETERMINISM_WITNESS=1` **before launching ComfyUI** and restart. It is
off by default. Use the same setting for all runs being compared. Repeated
`H3C-PT233 sampler-determinism receipt` JSON lines will appear in the normal
ComfyUI log, separately for `before_sample` and `after_sample` for each
actual Continuum H3 sampler invocation.

The receipt includes the resolved chunk seed and hashes of the exact noise,
latent, mask, sigma schedule, and numerical conditioning objects passed to the
sampler; it also hashes the returned sampled latent. Each tensor carries
shape/dtype and a SHA-256 of its **complete bytes**, never a sampled or mean
statistic. String metadata is hashed and prompt contents are not emitted. No
sampling data is mutated and no random numbers are generated by the observer.

Compare in execution order. If `before_sample` hashes differ, look first at
the reported field/tensor paths: changes in `noise` with matching shapes
usually indicate a different resolved seed, whereas changes in
`conditioning` implicate upstream encoding or reference processing.
Identical input hashes with different output hashes isolate the remaining
problem to execution behavior or unrecorded state (e.g. model weights, LoRA,
Spectrum cache, VDN backend, CUDA kernels); they do **not** establish which
component caused it. The hashes are deterministic only for equal tensor bytes.

The witness is not a solution to darkening or frame shifts. It does not prove
model/checkpoint or GPU backend state identity and cannot repair generation.
It synchronizes and copies tensors to CPU, so enabling it costs time and host
memory. Leave it disabled for normal generations. The observer deliberately
does not alter global deterministic-algorithm settings, kernels, sampler inputs,
ComfyUI cache keys, or any installed acceleration method.
